# 侍藍行程

離線 PWA 空殼。行程用 **WhatsApp 文字** 複製貼上，唔經伺服器、唔用 JSON。

## 用

1. 開 https://nik-neural.github.io/gojp/ （或本機 `python3 -m http.server`）
2. Safari → 加到主畫面
3. 「更多」→ 複製／貼上行程 → 貼文字 → 更新
4. 「行程」→ 編輯呢日
5. 改完撳「複製行程」，WhatsApp 傳團友，對方貼入自己部機

## 文字格式

```
侍藍行程
行程標題
v1｜日期

【團友】
名｜主駕駛或副駕駛｜航班號

【航班】
航班號｜月/日｜出發→到達｜邊個｜①

【住宿】
入住晚｜酒店名｜地址｜邊個｜①

【地點】
名｜搜尋字｜緯度,經度

【月/日】當日主題
09:00｜景點｜硬性｜①｜地點名
備註：可選

【未鎖】
未定事項｜②
```

①已確認 ②可能變 ③估算。人名、航班、確認號等只存在貼文同瀏覽器，唔放公開 repo。

## 地圖

主駕駛 → Gemini 導航（Google）。副駕駛 → Siri 導航（蘋果）。
